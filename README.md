# Tendril Alpha v0.3

Static, browser-local GitHub Pages prototype. Replace all six repository files with this package. Export a backup first.

## v0.3 highlights

- Action filtering and sorting with URL parameters
- Relationship rhythm-urgency sorting and cadence indicators
- Links from Relationships and Threads to filtered Actions
- Delete controls for Threads, Actions, and Relationships
- Replace and Merge import modes
- Clear-all-data flow with explicit confirmation
- Daily and Weekly Review snapshots
- Action editing and creation during Reviews
- Weekly focus relationships and encouragement opportunities
- Recent Review history

## Update notes

Existing v0.2 IndexedDB records remain compatible. After deployment, close all Tendril tabs, reopen the site, and refresh once so the v0.3 service worker activates.

## Data safety

Use Backup and data > Export Tendril data before updating or deleting. Replace import clears existing data before loading the selected file. Merge import retains current records and updates matching IDs.
